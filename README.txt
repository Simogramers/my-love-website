A LITTLE PLACE FOR YOU — GitHub Pages website

CUSTOMIZE YOUR WEBSITE
1. Add her photos into the images folder.
2. Name them exactly:
   - her-photo-1.jpg
   - her-photo-2.jpg
   - her-photo-3.jpg
   JPG, PNG or WebP files are fine, but if you use another extension, update the image paths in the HTML files.
3. Open letter.html and replace the sample letter with your own words.
4. In index.html, you can change "A little place just for you" or add her name.

PUBLISH WITH GITHUB PAGES
1. Create a new public GitHub repository, for example: my-love-website
2. Upload all the files and folders from this project. Keep the folder structure.
3. In the repository, open Settings → Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select branch "main" and folder "/ (root)", then Save.
6. Wait a minute or two. GitHub will show your website URL in Settings → Pages.

NOTES
- No backend, database, or build step is needed.
- The website is responsive and works on phones.
- Google Fonts need an internet connection. The rest of the site is static.
- The sample photo placeholders are only fallbacks. Replace them with her actual photos before publishing.
